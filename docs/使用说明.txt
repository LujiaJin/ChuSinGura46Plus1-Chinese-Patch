《ChuSinGura46+1 S》（忠臣蔵46+1）简体中文汉化补丁 v1.0
================================================================

【适用版本】
仅适用于 Steam 版《ChuSinGura46+1 S》（AppID 464780，当前构建 1370333，
即 Steam 目前分发的版本）。请先通过 Steam 正常安装并至少启动过一次游戏。

【安装步骤】
1. 双击 ChuSinGura46Plus1_ZH_Patch.exe（无需安装任何运行库，Windows 10/11 自带）。
2. 程序会自动查找游戏目录；若未找到，点「浏览…」手动选择游戏根目录
   （即包含 ChuSinGura46+1.exe 和 ChuSinGura46+1_Data 文件夹的目录）。
3. 确认状态显示两个文件均为「原版」后，点击「安装汉化」。
   - 安装前会自动备份原版文件（*.zh-backup），随时可点「恢复原版」还原；
   - 若游戏装在 Program Files 等受保护目录，会请求一次管理员权限（UAC 弹窗）。
4. 从 Steam 启动游戏，在游戏中右键（或点设置按钮）打开环境设置，
   把「言語 / Language」循环切换到「简体中文」即可。

【注意事项】
- 安装/恢复前请先完全退出游戏。
- 补丁只包含与原版的差异数据，安装时在你本机的游戏文件上应用；
  应用结果经过哈希校验，与实测通过的版本逐字节一致。
- 若游戏将来更新（文件校验不匹配），安装器会拒绝安装并提示，
  请先在 Steam 中对该游戏执行「校验文件完整性」后再试。
- 想卸载汉化：点「恢复原版」；或直接在 Steam 中校验文件完整性。
- 从网络下载的未签名程序可能会触发 Windows SmartScreen 提示，
  点「更多信息」→「仍要运行」即可。

【已知说明】
- 中文模式下的界面底图沿用英文版 UI 图片（按钮图标、菜单边框），
  剧情、人物名、选项均为简体中文。
- 存档与原版互通；语言只是游戏内设置项，随时可切回英文/日文。
