# 忠臣蔵46+1 PC 版（KiriKiri）简体中文补丁

适用于 **ChuSinGura46+1 PC 版**（KiriKiri/krkr2 引擎，光盘版 / DL 版）的完整简体中文汉化补丁。这是本仓库的**主打补丁**。

> Steam 版（Unity 重制版）补丁请看 [steam-s/](../steam-s/)。

## 下载安装

1. 从 [Releases](https://github.com/LujiaJin/ChuSinGura46Plus1-Chinese-Patch/releases) 下载 **`ChuSinGura46Plus1_PC_ZH_Patch_v2.2.zip`**
2. 解压得到 `patch.xp3`
3. 将 `patch.xp3` 复制到游戏安装目录（与 `bgimage.xp3`、`scenario.xp3` 等同一层）
4. 启动游戏即为简体中文

卸载：删除 `patch.xp3` 即恢复日文原版。

## 已知事项

- 「追加内容 → 片头动画」播放结束后可能无响应——**日文原版同样存在**（引擎视频组件缺陷，与补丁无关），重启游戏即可，或改用「影像鉴赏」入口观看
- 部分内容需通关解锁（游戏进度机制）
- 人物录详情页（43 张角色介绍图）尚未汉化，列入后续批次
- 测试新补丁前请**完全退出游戏进程**再替换文件（KiriKiri 启动时锁定 XP3 归档）

## 本目录内容

`tools/` 为构建工具链（Python 3）：

- `xp3lib.py` — 本作自定义加密 XP3（csg.tpm 29 字节 XOR 表）的读写库
- `build_full_patch.py` — 从 `zh_out/` 构建完整 `patch.xp3`
- `fix_*.py` — 各页面素材的图像级汉化脚本（标题/人物录/DANGER/配置页/按钮等）

> 仓库遵循既定原则：不收录游戏原文与译文语料（版权原因），补丁成品通过 Release 附件分发。
